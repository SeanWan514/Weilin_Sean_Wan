Cost-efficient learning for algorithm selection

Active Learning for Molecular-Docking Algorithm Selection under Heterogeneous Runtime

As a fully funded DKU Summer Research Scholar, I built a retrospective active-learning pipeline for molecular-docking algorithm selection. The work studies how partial acquisition can produce useful selector-training data when docking runtimes differ.

Research question

How can partial acquisition of docking outcomes support algorithm selection while accounting for heterogeneous runtime and downstream decision quality?

My contributions

  • Integrated cell-wise acquisition, low-rank matrix completion, and runtime models fitted only to previously observed training-pool runtimes.
  • Trained downstream selectors on completed performance matrices while reserving held-out docking outcomes for evaluation.
  • Compared runtime-aware acquisition with Mean-UCB using realized docking cost, per-engine query allocation, and held-out selector performance.
  • First-authored the paper accepted at the NeurIPS 2026 Workshop on AI for Drug Discovery.

Findings

  • Partial acquisition yielded decision-useful training data for docking algorithm selection.
  • The evaluation identified budget-dependent trade-offs between acquisition cost and downstream quality.
  • Matrix-reconstruction metrics did not consistently track downstream docking performance.

Scope & current status

  • The study uses retrospective active learning, with runtime models fitted only to previously observed training-pool runtimes.
  • Cost–quality trade-offs depend on the acquisition budget, and reconstruction quality alone does not consistently indicate selector performance.
